# Lumenfall

Lumenfall is an original arena survival roguelite built for the make.fun `best-game-01` competition. Step into the Hollow as the Lumen Warden, a small glowing orb of light alone in a dark arena. Void motes swarm from the edges in escalating numbers. Survive, gather lumen shards, level up, choose powerful upgrades, and defeat the Void Matriarch boss to claim victory.

## How to Play

- **Movement:** WASD or Arrow Keys.
- **Aiming & Firing:** Mouse aims automatically. Lumen bolts fire continuously toward the cursor (or nearest enemy if the mouse hasn't moved).
- **Flare Burst:** Click or press Space to trigger a radial Nova that damages nearby enemies (consumes 1 flare charge).
- **Upgrades:** Collect lumen shards dropped by defeated enemies to gain XP, level up, and choose from 3 random upgrades.
- **Controls:** `P` or `Esc` to pause, `M` to toggle audio mute, `R` to restart from end screens.

## Running Locally

1. Install dependencies (Node.js 22+ standard library required).
2. Start the local server:
   ```bash
   node serve.ts
   ```
3. Open `http://localhost:8080` in your browser.
